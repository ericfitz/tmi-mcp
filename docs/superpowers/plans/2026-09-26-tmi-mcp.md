# tmi-mcp Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A local Go stdio MCP server that wraps the generated TMI Go client so agents can do threat-modeling work, with a lazy PKCE browser login and persisted tokens.

**Architecture:** One binary (`cmd/tmi-mcp`). `internal/config` resolves named profiles; `internal/tokenstore` persists tokens (keychain, file fallback); `internal/auth` does PKCE loopback login, refresh, revoke; `internal/session` hands out an authenticated client per profile and retries once on 401; `internal/tools` registers resource-grouped MCP tools with an `action` argument.

**Tech Stack:** Go 1.27 toolchain; `github.com/modelcontextprotocol/go-sdk` v1.8.0 (`mcp` package); `github.com/ericfitz/tmi-clients/go-client-generated/v1_15_0` at pseudo-version `v0.0.0-20260926182318-0e6a703f28ba` (package name `tmiclient`, import alias `tmi`); `github.com/zalando/go-keyring` v0.2.8; `go.yaml.in/yaml/v3`; golangci-lint v2.

**Spec:** `docs/superpowers/specs/2026-09-26-tmi-mcp-design.md`

## Global Constraints

- Module path: `github.com/ericfitz/tmi-mcp`. Work directly on `main` (user-approved for this first implementation only).
- stdout carries only MCP protocol traffic. All logs go to stderr. Never log tokens.
- Config default path: `$XDG_CONFIG_HOME/tmi-mcp/config.yaml`, else `~/.config/tmi-mcp/config.yaml` (NOT `os.UserConfigDir`, which is `~/Library/Application Support` on macOS).
- Token file fallback: `<config dir>/tokens/<profile>.json`, file mode 0600, directory mode 0700. Keychain service name `tmi-mcp`, account = profile name.
- Login: listen on `127.0.0.1:0`; callback path `/callback`; `client_callback=http://127.0.0.1:<port>/callback`; PKCE S256; scope `openid profile email`; timeout 2 minutes.
- Access token considered expired when fewer than 60 s remain.
- Every tool takes an optional `profile` string. Actions are validated in the handler; unknown action or missing required argument is a tool error naming the problem.
- `update` = partial `fields` object → one JSON Patch `add` op per top-level key at `/<key>` → PATCH endpoint.
- Tool errors, not protocol errors, for all TMI/API/login/argument failures (the go-sdk turns a handler `error` into `isError: true` content automatically).
- macOS host has no GNU `timeout`; use `go test -timeout`.
- Lint with `golangci-lint run ./...`; tests with `go test ./...`.

## Review Focus

1. **Browser never reaches the callback** (allowlist rejection, user closes tab): the tool must fail fast with the allowlist hint (preflight) or time out at 2 min with a clear message, and the listener must be closed. Test: Task 3 preflight-400 test and timeout test.
2. **Concurrent first calls on one profile** must produce exactly one login, not N browser tabs. Test: Task 4 concurrency test counting login invocations.
3. **Refresh token rejected/expired** must fall through to interactive login, not return the refresh error. Test: Task 4 refresh-fails test.
4. **401 mid-session** (token revoked server-side while `expires_at` still in future) must refresh and retry exactly once, and a second 401 surfaces as a tool error with a "log in again" hint. Test: Task 4 retry tests.
5. **Corrupt or unreadable config/token file** must produce an actionable error (path + reason), and a corrupt token file must be treated as "no tokens" so the user can simply log in again. Test: Task 1 bad-YAML test, Task 2 corrupt-file test.

```go
// Package config loads tmi-mcp's profile configuration.
package config

import (
	"fmt"
	"os"
	"path/filepath"
	"sort"
	"strings"

	"go.yaml.in/yaml/v3"
)

type Profile struct {
	Name      string `yaml:"-"`
	Server    string `yaml:"server"`
	IDP       string `yaml:"idp"`
	LoginHint string `yaml:"login_hint"`
}

type Config struct {
	DefaultProfile string             `yaml:"default_profile"`
	Profiles       map[string]Profile `yaml:"profiles"`
}

// Dir returns $XDG_CONFIG_HOME/tmi-mcp, else ~/.config/tmi-mcp.
func Dir() (string, error) {
	if x := os.Getenv("XDG_CONFIG_HOME"); x != "" {
		return filepath.Join(x, "tmi-mcp"), nil
	}
	home, err := os.UserHomeDir()
	if err != nil {
		return "", err
	}
	return filepath.Join(home, ".config", "tmi-mcp"), nil
}

func Load(path string) (*Config, error) {
	b, err := os.ReadFile(path)
	if err != nil {
		return nil, fmt.Errorf("read config %s: %w", path, err)
	}
	var c Config
	if err := yaml.Unmarshal(b, &c); err != nil {
		return nil, fmt.Errorf("parse config %s: %w", path, err)
	}
	if len(c.Profiles) == 0 {
		return nil, fmt.Errorf("config %s: no profiles defined", path)
	}
	for name, p := range c.Profiles {
		if p.Server == "" {
			return nil, fmt.Errorf("config %s: profile %q has no server", path, name)
		}
	}
	if _, ok := c.Profiles[c.DefaultProfile]; !ok {
		return nil, fmt.Errorf("config %s: default_profile %q is not a defined profile (have: %s)",
			path, c.DefaultProfile, strings.Join(c.Names(), ", "))
	}
	return &c, nil
}

func (c *Config) Names() []string {
	names := make([]string, 0, len(c.Profiles))
	for n := range c.Profiles {
		names = append(names, n)
	}
	sort.Strings(names)
	return names
}

func (c *Config) Resolve(name string) (Profile, error) {
	if name == "" {
		name = c.DefaultProfile
	}
	p, ok := c.Profiles[name]
	if !ok {
		return Profile{}, fmt.Errorf("unknown profile %q (have: %s)", name, strings.Join(c.Names(), ", "))
	}
	p.Name = name
	return p, nil
}
```

**Implementation notes:**
- `NewAPIClient`: `cfg := tmi.NewConfiguration(); cfg.Servers = tmi.ServerConfigurations{{URL: strings.TrimRight(server, "/")}}; cfg.UserAgent = "tmi-mcp"; return tmi.NewAPIClient(cfg)`.

- `NewPKCE`: 32 random bytes → `base64.RawURLEncoding` verifier (43 chars); challenge = `RawURLEncoding(sha256(verifier))`.
- `Login` steps:
  1. `ln, _ := net.Listen("tcp", "127.0.0.1:0")`; `callback := fmt.Sprintf("http://127.0.0.1:%d/callback", port)`.
  2. PKCE + `state` (16 random bytes, RawURLEncoding).
  3. Build authorize URL with `url.Values`: `idp` (omit if empty), `client_callback`, `code_challenge`, `code_challenge_method=S256`, `state`, `scope="openid profile email"`, `login_hint` (omit if empty). URL = `server + "/oauth2/authorize?" + q.Encode()`.
  4. **Preflight** (Review Focus 1): `http.Client{CheckRedirect: func(...) error { return http.ErrUseLastResponse }, Timeout: 10*time.Second}` GET the authorize URL. If status is 400 and body contains `allowlist`, return error: `TMI rejected the login callback: add "http://127.0.0.1:*" to auth.oauth.client_callback_allowlist on <server>`. Any other 4xx/5xx → error with status and body. Otherwise continue (discard the preflight response; each authorize call makes its own state).
  5. Serve `/callback` on `ln` with `http.Server`. Handler: if `state` query ≠ ours → 400 page, send error "state mismatch". If `error` query present → error page, send `fmt.Errorf("login failed: %s", e)`. Else send code. Page body: `<html><body><h3>TMI login complete. You can close this tab.</h3></body></html>` (or the error). Use a buffered `chan result` of size 1 with non-blocking send so duplicate hits don't block.
  6. `notify(fmt.Sprintf("Opening browser for TMI login (profile %s)…", p.Name))`; `fmt.Fprintf(os.Stderr, "tmi-mcp: open this URL to log in: %s\n", authURL)`; `OpenBrowser(authURL)` (error only logged; the URL on stderr is the fallback).
  7. `select` on result, `ctx.Done()`, `time.After(LoginTimeout)` → timeout error `"TMI login timed out after 2m0s (profile <name>)"`. `defer srv.Close()` always.
  8. Exchange: `req := tmi.NewExchangeOAuthCodeRequest("authorization_code")`; `req.SetCode(code)`, `SetCodeVerifier(verifier)`, `SetRedirectUri(callback)`, `SetState(state)`; `NewAPIClient(server).AuthenticationAPI.ExchangeOAuthCode(ctx).ExchangeOAuthCodeRequest(*req)` plus `.Idp(p.IDP)` when non-empty; `Execute()`; on error return `AsAPIError(err, resp)`.
  9. Return `&tokenstore.Tokens{AccessToken, RefreshToken, ExpiresAt: time.Now().Add(time.Duration(ExpiresIn)*time.Second)}`.

```go
package auth

import (
	"context"
	"crypto/sha256"
	"encoding/base64"
	"encoding/json"
	"io"
	"net/http"
	"net/http/httptest"
	"net/url"
	"strings"
	"sync/atomic"
	"testing"
	"time"

	"github.com/ericfitz/tmi-mcp/internal/config"
)

type fakeTMI struct {
	*httptest.Server
	challenge   string
	rejectCB    bool
	denied      bool
	tokenCalls  atomic.Int32
}

func newFake(t *testing.T) *fakeTMI {
	f := &fakeTMI{}
	mux := http.NewServeMux()
	mux.HandleFunc("/oauth2/authorize", func(w http.ResponseWriter, r *http.Request) {
		q := r.URL.Query()
		if f.rejectCB {
			w.WriteHeader(400)
			_, _ = io.WriteString(w, `{"error":"invalid_request","error_description":"client_callback is not in the allowlist"}`)
			return
		}
		if q.Get("code_challenge_method") != "S256" || q.Get("scope") != "openid profile email" {
			w.WriteHeader(400)
			return
		}
		f.challenge = q.Get("code_challenge")
		cb := q.Get("client_callback")
		if f.denied {
			http.Redirect(w, r, cb+"?error=access_denied&state="+url.QueryEscape(q.Get("state")), http.StatusFound)
			return
		}
		http.Redirect(w, r, cb+"?code=thecode&state="+url.QueryEscape(q.Get("state")), http.StatusFound)
	})
	mux.HandleFunc("/oauth2/token", func(w http.ResponseWriter, r *http.Request) {
		f.tokenCalls.Add(1)
		var body map[string]any
		_ = json.NewDecoder(r.Body).Decode(&body)
		sum := sha256.Sum256([]byte(body["code_verifier"].(string)))
		if body["code"] != "thecode" || base64.RawURLEncoding.EncodeToString(sum[:]) != f.challenge {
			w.WriteHeader(400)
			return
		}
		w.Header().Set("Content-Type", "application/json")
		_, _ = io.WriteString(w, `{"access_token":"AT","refresh_token":"RT","token_type":"Bearer","expires_in":3600}`)
	})
	mux.HandleFunc("/oauth2/refresh", func(w http.ResponseWriter, r *http.Request) {
		var body map[string]any
		_ = json.NewDecoder(r.Body).Decode(&body)
		if body["refresh_token"] != "RT" {
			w.WriteHeader(401)
			return
		}
		w.Header().Set("Content-Type", "application/json")
		_, _ = io.WriteString(w, `{"access_token":"AT2","refresh_token":"RT2","token_type":"Bearer","expires_in":3600}`)
	})
	f.Server = httptest.NewServer(mux)
	t.Cleanup(f.Close)
	return f
}
```

**Behavior:**
- `token(ctx, p, n, forceRefresh bool)` holds the per-profile lock for the whole acquire (Review Focus 2): load; if valid and not forced → return; if refresh token → `RefreshFn`; success → save and return; failure → log to stderr and fall through (Review Focus 3); then `LoginFn` → save → return.
- `Call`: resolve profile; `tok := token(...)`; `ctx2 := context.WithValue(ctx, tmi.ContextAccessToken, tok.AccessToken)`; `v, resp, err := fn(ctx2, client(p))`; if `resp != nil && resp.StatusCode == 401` → `token(..., forceRefresh=true)` and retry once (Review Focus 4); final `err != nil` → return `auth.AsAPIError(err, resp)`.
- `client(p)` caches one `*tmi.APIClient` per profile name.
- `Logout`: load tokens; if present and refresh token non-empty, `RevokeFn` (log failure to stderr, don't return it); then `Store.Delete`.
